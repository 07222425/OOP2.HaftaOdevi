# OOP 2.Hafta Ödevi
Bu depo, Java OOP prensiplerinin uygulanmasına odaklanan 11 bağımsız NetBeans projesini içermektedir. Her egzersiz kendi paketi ve sınıf hiyerarşisiyle izole edilmiştir; böylece encapsulation, inheritance ve composition kavramları pratik senaryolar üzerinden test edilmiştir. UML sınıf diyagramları implementation öncesi tasarlanmıştır ve PlantUML kaynak kodları uml/ dizininde vektörel formatlarda saklanmaktadır. StopWatch uygulamasında selection sort performansı milisaniye bazında benchmark edilmiş, Account ve LinearEquation sınıfları ise edge-case kontrolleriyle birlikte unit-test mantığına uygun şekilde yapılandırılmıştır. Kod standardı, her sınıfın tek bir sorumluluğu üstlenmesi ve paket bazlı erişim kontrolünün sıkı uygulanması üzerine kuruludur.
